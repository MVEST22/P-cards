# P-card Auditor — AI in Accounting Assignment 2

Live application: https://name-pcard-auditor.onrender.com

This app helps explore purchasing-card transactions for audit review. The underlying database contains 2014 Oklahoma State University P-card records.

## Coursework results
- Part II: 14 internal-control screening tests
- Part III: eight fraud-risk screening tests
- [Read the results and concise explanations](audit/ASSIGNMENT_2_AUDIT_RESULTS.md)
- Part IV: public web interface and search tools

The screening results are indicators for follow-up, not evidence of fraud or policy violations. Full supporting SQL outputs and annotated audit answers are provided separately to the instructor.
